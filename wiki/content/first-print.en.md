# Your first print

Connect your Paperang P2 to a client, compose a short note, and check the preview before sending it.

## 1. Choose a client

| Platform | Install | Connect the printer |
| --- | --- | --- |
| macOS 14+ on Apple Silicon | Download MacClient from [GitHub Releases](https://github.com/ELT17604/Paperang-Studio/releases/tag/v0.3.3) | Open Printer and scan for the P2 over Bluetooth |
| Android 13+ | [Install AndroidClient](/en/android/) | Open Printer, allow Nearby Devices access, and scan for the P2 |
| Windows 10 2004+ or Windows 11 | [Install WinClient](/en/windows/) | Open Printer in the workspace and connect over USB or Bluetooth |

## 2. Compose and preview

Enter a short line of text or import an image. Check the black-and-white preview, then set density and feed for your paper. The P2 workspace uses a printable width of 576 dots.

## 3. Print

Select the connected P2 and send the preview. If it does not appear during a scan, check that the printer is powered on and Bluetooth is enabled. On WinClient, you can also use USB. The client guides cover each platform's connection settings and print controls.

## Where to go next
