# 第一次打印

连接 Paperang P2，编辑一张短纸条，检查黑白预览后发送打印。

## 1. 选择客户端

| 平台 | 安装 | 连接打印机 |
| --- | --- | --- |
| macOS 14 及以上（Apple 芯片） | 从 [GitHub Releases](https://github.com/ELT17604/Paperang-Studio/releases) 下载 MacClient | 在「打印机」页通过蓝牙扫描 P2 |
| Android 13 及以上 | [构建并安装 AndroidClient](/zh-CN/android/) | 在「打印机」页授权附近设备权限，再扫描 P2 |
| Windows 10 2004 及以上或 Windows 11 | [安装或构建 WinLite](/zh-CN/windows-build/) | 从托盘打开设置，通过 USB 或蓝牙连接 |

## 2. 编辑并预览

输入一行简短文字，或导入一张图片。检查黑白预览，再根据纸张调整浓度和送纸。P2 工作台的可打印宽度为 576 点。

## 3. 发送打印

选中已连接的 P2，发送预览内容。扫描不到设备时，检查打印机是否开机以及蓝牙是否启用。WinLite 也可通过 USB 连接。各平台的连接选项和打印控制见客户端指南。
