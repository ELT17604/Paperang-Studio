# 远程任务列表与图形化样式编辑器

[English](LAYOUT-EDITOR.md) · [中文文档目录](INDEX.zh-CN.md)

## 任务列表与短编号

任务列表显示投稿人、正文摘要、时间、状态和短编号，可按状态筛选，或搜索编号/身份/正文。点击任务加载完整内容、来源元数据、结果和完整内部ID。仅待处理任务可以确认打印/拒绝；已发送、已拒绝或结果不确定的记录不会自动重打。需要人工重印时先核对纸面，再“复制正文到工作台”。

完整内部ID为40位小写十六进制，使用时间和密码学随机输入的SHA-256摘要截取160位生成，数据库主键拒绝重复。只是外形类似commitID，并非Git提交或访客正文的摘要。

纸面使用独立分配的**12位大写十六进制短编号**，如`A1B2-C3D4-E5F6`。SQLite唯一索引和碰撞重试保证在同一数据库内不重复；不同安装之间不承诺全球唯一。短编号不是鉴权凭据，API路径仍使用完整ID。旧UUID任务自动保留并补充分配短编号。

短编号默认不打印：内置样式勾选“短编号”，自定义样式启用“任务编号”区块或使用`{{id}}`。完整40位内部ID只在详情中查阅。

列表API返回最多100个活动/近期摘要，优先保留活动任务；长正文标记truncated，打印前必须从详情接口获取全文，不会把摘要当正文打印。自动模式按待处理任务的先后顺序处理，与界面筛选无关。

## 默认自动打印

首次使用默认关闭。可开启“下次连接默认自动打印”，保存在本机偏好中。下一次连接会开启运行时自动模式，但仍要求P2就绪、侧栏全局允许耗纸、设备空闲、没有未解决的在途远程任务。关闭全局耗纸会关闭本次自动模式；失败会暂停自动打印，不会自动重发不确定任务。模板和选中样式本地保存，中转密钥不持久保存。

## 图形化编辑器

进入“远程打印→图形化样式编辑器”。使用选中任务的完整正文或离线示例进行预览。编辑草稿不会影响正在使用的模板，点击保存才生效。

- 模板栏：选择、改名、复制、载入四种预设、导入/导出JSON、删除模板。
- 区块列表：增删、拖动排序，也可使用上移/下移。
- 属性区：启用、内容字段、字体、字号、粗体、对齐、左右边距、上方留白。
- 纸面画布：点击区块选择；横向拖动调边距，纵向拖动调上方留白。区块顺序流式排版，长正文会推开后续区块，不重叠。
- 保存并应用：验证后保存到本机偏好，并切换“自定义”样式。取消会丢弃草稿。

区块有标题、正文、投稿身份、时间、任务编号、IP、UA、浏览器信息、分隔线、自定义文字。自定义文字支持`{{text}} {{sender}} {{id}} {{time}} {{ip}} {{ua}} {{device}}`，仅对模板替换一次，不会递归展开访客正文中的类似变量。

最多30模板、每模板24区块，模板名80字符，自定义文字每区块2000字符，字号8–96、左右边距0–120点、上方留白0–200行。导入文件最多64KiB且校验参数。所有区块使用统一渲染器生成1位位图，再逐行合并与补白，固定576点宽、最高1400行；预览和打印使用相同合成方法。

自定义样式的字段由区块启用状态决定，页面中的内置字段复选框会禁用。初始预设不默认启用IP/UA/设备信息或任务编号；导入的模板应先预览再开启自动打印。

## 自定义模板中的图片任务

正文区块同时接收文字和点阵任务。图片按区块的左右边距等比适配，可选说明文字紧随图片，中间留 4 行；字体、粗体和对齐用于说明文字。图片用黑白最近邻缩放，边距 0 保持原字节。调整顺序会移动整个正文区块，关闭正文会同时隐藏图片和说明。其他区块继续保持原渲染、顺序和留白。旧版 v1 模板 JSON 无需迁移；编辑器、任务预览、复制到工作台和打印共用模板区块及最终合成器。内置字段复选框不覆盖自定义区块开关。包含所有留白的总高度仍限 1400 行。

客户端 v0.2.3-fix1 对编辑器与任务预览使用排序后的稳定模板签名。生成预览会按需读取完整任务，并显示加载/失败状态；无关的轮询或状态更新不会清除有效预览。任务内容或布局变化后，旧预览会失效，重新生成即可。本次修复无需更新服务端或网页。
