# 菜单栏托盘模式 · v0.2.3

[English](TRAY-MODE.md) · [用户手册](USER-GUIDE.zh-CN.md)

点击侧栏底部或“文件”菜单的“进入托盘模式”：隐藏主窗口与 Dock 图标，在 macOS 顶部菜单栏保留打印机图标。点图标可查看蓝牙、本地 API 真实监听状态、中转在线/重试/错误、打印进度，并可暂停/恢复网络打印、复制 API 令牌、恢复主界面或退出。

进入托盘即授权本次会话的无人值守网络任务打印：按配置启动本地鉴权 API，保持已有蓝牙和中转连接，并为正在运行的中转开启自动处理。请先连接打印机、配置并连接中转；模式不会自动寻找其他设备，也不会修改系统蓝牙设置或保存密钥。设备就绪、纸仓检查、浓度回读、数据大小限制、中转失败重试 5 次后断开等规则继续生效。中转失败后保持断开，托盘显示警告与图标提示；恢复主界面后手动重连。

进入时停止 PTY shell 和空闲打印计时器，取消工作台预览与选中任务读取，隐藏期间不自动刷新工作台预览。网络任务仍会进行必要的排版、校验和发送。不会主动执行终端输出打印或工程指令。已开始的打印可能继续完成，设备缓存的数据不能撤回。托盘是当前用户会话中的 App，不是系统服务、开机启动项或防休眠工具；退出、注销、系统休眠可能中断通信。

## 网络授权

托盘网络授权独立于侧栏“全局允许耗纸”，不会自动打开工作台打印权限。`GET /v1/status` 返回 appVersion、trayMode、networkPrintAllowed、automaticNetworkConsent、workspacePrintingEnabled 和 printingEnabled（当前有效网络权限）。权限不等于打印机就绪或纸面完成。本地 API 是否在线以监听回调为准，端口占用会显示失败。

| 模式 | 本地 POST /v1/jobs | 中转任务 |
|---|---|---|
| 普通模式 | 全局耗纸开启且请求 allowPaper:true | 原有手动/自动偏好 |
| 托盘运行 | 可省略 allowPaper；显式 true 接受，false 或错误类型拒绝 | 就绪后自动处理新排队任务 |
| 托盘暂停 | 新任务返回 403 | 暂停自动领取 |

Bearer 鉴权、Origin 白名单和仅 127.0.0.1 监听继续生效。单独送纸接口仍需有效网络权限和显式 allowPaper:true；任务自带的浓度/批后送纸照常执行。暂停针对新提交/领取，已经在发送或进入设备缓存的数据可能继续完成。结果不确定的任务不自动重打；数据发送完成与人工确认纸面仍分开。

恢复主界面即退出托盘，移除菜单栏图标，恢复进入前的中转自动打印偏好；只有托盘临时启动的本地 API 才会停止，原本已启动的监听会保留。工作台耗纸开关不变，不自动重启 shell，也不跨 App 启动保存托盘授权。

## v0.2.3 同步范围

App 包版本、关于、侧栏、托盘菜单、仓库 VERSION、服务端版本和状态、网页标题/页脚/meta、SDK 包、OpenAPI 及当前文档同步为 0.2.3。历史变更和第三方依赖版本保留。App 和服务端需要重启，静态网页文件应同批部署。公共状态返回 version:"0.2.3"；新鲜设备遥测中的 relayAutomaticPrinting（旧客户端回退 automaticNetworkConsent）决定 status.automaticPrinting，网页据此提示自动打印模式。

托盘期间重新打开/激活 App 不会结束后台会话；请通过菜单栏的“恢复主界面”明确退出并恢复权限。

relayAutomaticPrinting 表示中转自动处理器是否真正开启；网页优先使用它，避免在打印出错暂停处理后，仅凭网络授权仍开启就误报自动处理。托盘也单独展示中转自动处理开关状态。

Python/JavaScript SDK 的打印方法默认省略单次授权字段，以便托盘自动授权；显式 false 仍拒绝，普通模式仍需显式 true。
