# MacClient 0.3.1 fix3 升级说明

[English](MACCLIENT-v0.3.1.md) · [使用指南](USER-GUIDE.zh-CN.md)

2026-11-09，从上游 `9471293` 升级。MacClient 为 **0.3.1-macclient-fix3**；服务器仍为 0.3.1-linuxrelayserver-fix1，WinLite 仍为 0.3.1-winlite-fix3。中转 API v2、本地 API v1、模板 v1、raster1 schema1 不变。

## 连接与恢复

远程打印中选择配对的所有者私钥 JSON，确认服务器地址后连接。文件必须绑定该服务器。通过 RSA-PSS 获取短期会话并自动续期；401 拒绝后续期重试一次。稳定指纹采用配对 ID 与 SPKI 的 SHA-256，与 Windows 一致。兼容现有 M 密钥，但服务器切换所有者模式时已吊销的 M 密钥无法继续使用。

活动连接恢复记录与未完成的连接草稿分别保存在 Keychain。断开不会把已发送结果降为未知；不确定任务只回报结果，不自动重打。正文仅在活动认领中读取；完整历史需独立 C 管理会话。任务认领前固定模板和打印设置，避免处理中修改界面影响当前任务。

## 设置与管理

自动保存有效的打印参数、模板、界面偏好和连接草稿。启动连接、记住的打印机重连均需手动开启，不会自动授予全局耗纸许可。导出配置包含设置、模板、界面偏好和私钥文件路径，不包含凭证、私钥内容、会话、待回报结果或任务正文；路径可能透露本地目录名，请自行保管。私钥原文件应单独保存。

C 管理中心提供凭证、身份、会话、历史和审计；点击记录读取文字、图片和原始 JSON。支持每页 25/50/100 条，最多缓存 12 页摘要，兼容旧服务器固定分页。支持新建凭证并复用身份、改名、轮换和吊销；口令留空随机生成，自定义口令无复杂度要求。配额空白表示继承，0 与继承不同；写入前必须读取相应作用域。生成私钥使用服务端实际配对 ID，并拒绝覆盖文件。历史可流式导出 JSONL。管理会话十分钟锁定，与后台接收独立。
