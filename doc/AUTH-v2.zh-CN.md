# v0.3.0 身份与鉴权

[English / 完整端点合同](AUTH-v2.md) · [升级操作](UPGRADE-v0.3.0.zh-CN.md) · [跨平台接手 prompt](HANDOFF-v0.3.0.zh-CN.md)

本次用户确认采用 0.3.0 作为破坏性升级基线，所有中转参与方必须一起升级到 API v2。Mac 本地 HTTP API 仍为 v1；模板版本 1、raster1 和 BLE 协议保持兼容。服务器旧 /v1 路由统一返回 410，旧 receipt 不再授予任何读取权限。

| 权限 | 投递 | 查看状态 | 历史正文及投递信息 | 管理 |
|---|---|---|---|---|
| A（匿名默认） | 是 | 403，无权限 | 否 | 否 |
| B | 是 | 仅本身份 | 否 | 否 |
| C | 是 | 全部 | 全部；筛选、分批导出 | 全部业务凭证、身份、会话、公钥 |
| M（打印执行） | 否 | 限定设备待处理队列 | 仅认领后的活动任务 | 回报自己认领的结果 |

A 只收到“投递已受理”和任务编号，不把受理伪装成打印成功。B/C 的普通任务查询始终只返回 id、shortID、state、created、updated；不返回正文、图片、缩略图、IP、UA、自由文本错误或其他投递信息。完整信息只能从 C 管理接口读取。公共接口只展示投稿策略和能力，不展示打印机状态。

身份 user_id、浏览器实例 browser_id 和 credential id 分开。轮换凭证不改变 user_id，因此历史可继续按唯一用户筛选；改名不重写历史名称快照。共享口令代表共享身份，不能证明是同一个自然人。

网页输入口令后，用 Secure、HttpOnly、SameSite=Strict Cookie 长期保存登录会话（普通身份默认最长 180 天，可用 session_days 调整为 1–180 天；C 为十分钟）。浏览器本地只保存随机 psb_+32 位十六进制实例标签和最近二十个任务编号，不存原始口令。匿名必须先注册随机实例并通过 auth/me 确认服务器身份，未生成完成的任务被拒绝。无法可靠获得硬件身份，IP 变化也不会改变有效 Cookie 的身份；清除 Cookie 或隐身会产生新身份，不能据此承诺永久封禁一个人。

随机 API 密钥保存 SHA-256 摘要；人类口令使用 Argon2id 和独立随机盐，输入形式 psp_<凭证 UUID>.<口令>，默认生成高熵口令，自定义至少十二字符。登录/注册有限流，投稿同时限制 IP、身份、凭证和全局用量。旧口令无法取回；创建或轮换只显示一次新秘密。

所有者文件包含绑定服务器地址、公钥凭证 id、本地 RSA 私钥 PEM。服务器预先登记公钥，签名证明持有权后才激活。Windows 使用原生 RSA-PSS/SHA-256，盐长 32 字节；挑战六十秒且仅能消费一次，成功得到十分钟 C 会话。此方案是 HTTPS 挑战鉴权，并非 SSH 协议，也不宣称完整实现 RFC 9421。Windows 在写入秘密前建立仅当前用户可访问的 ACL；Mac 文件设为 0600。私钥绝不上传。无人值守打印继续使用 M，不把最高权限永久交给后台循环。

WinLite 设置→管理中有原生图形面板：C/私钥登录、凭证创建/改名/轮换/吊销、身份吊销、会话管理、公钥登记、完整历史和审计、按 user_id 筛选、流式 JSONL 导出（图片作为 raster1/base64 随任务导出）。Mac 同步提供 SwiftUI 管理面板源代码，须在 macOS 编译验证。JSONL 不执行 CSV 公式；CSV 和独立附件目录导出本版不提供。

普通轮换撤销旧会话，已排队任务继续；吊销身份默认拒绝其排队任务。已经开始发送或进入打印机缓存的数据无法召回。当前管理员不能吊销自身；最后一个已证明有效的 C 受保护。sent 仍仅表示发送完成，只有实际检查纸面后才能确认 confirmed。不确定结果不自动重印。

数据库正文与投递信息仍为明文，建议使用系统磁盘加密；应用级正文加密不是本版已实现功能。默认任务保留七天，审计九十天。详细字段、路由、分页及限制以英文合同和实际实现为准。
