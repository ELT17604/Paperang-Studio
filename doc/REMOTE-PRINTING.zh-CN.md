# 远程打印与部署

中转 API v2、A/B/C/M 权限、浏览器身份、私钥文件和历史管理见[鉴权文档](AUTH-v2.zh-CN.md)。部署参数见[Server 指南](../Server/README.md)，已有实例必须先按[升级与回滚步骤](UPGRADE-v0.3.2.md)操作。

Windows：WinClient「远程打印」保存中转地址与配对私钥或 M 执行凭证；「打印机」选择设备，「访问与任务管理」独立使用 C 凭证/私钥登录。详见 [Windows 指南](WINDOWS.zh-CN.md)。Mac：远程打印页选择配对所有者文件或 M 设备凭证；C 面板用于完整历史、预览与管理。后台按设备向外轮询，无需给客户端开放公网端口。模板/浓度/送纸仍在客户端本地控制，支持 text 和 raster1。

网页使用持久安全 Cookie，匿名首次注册成功前禁止投稿。A 受理后不显示打印状态；B 查看本身份状态，正文只在 C 客户端管理面板中读取。公共网页不再展示设备遥测，旧 receipt 不能取正文。先认领再取正文，unknown 不自动重印；纸面确认须 C 手动核对。
