# MacClient 打印工作台

在「文字」模式打开字体选择器。常用字体列在顶部，向下滚动可浏览 macOS 提供的全部字体，也可按名称搜索。

1. 打开「高级排版…」，设置模拟纸张长度。纸宽固定为 576 点。
2. 点击或拖入文字框、标签、图片和二维码。也可从 Finder 把图片文件拖到纸面。选中对象后可以拖动位置，在右侧精调位置和尺寸，或把对象移到最上层。
3. 在右侧编辑文字框或标签。用对齐按钮设置整个框的排版。选中一个字或一段文字，再打开「字体与样式…」调整该范围的字体、字号和字形。
4. 在二维码属性中选择纯文字、网页链接或电子邮件，填写内容，再调整纠错级别、方形／圆角／圆点模块和外框。内容越长需要的空间越大。建议用最终黑白预览扫码，实际出纸后再核对，避免图层遮挡、反相或过小的模块影响识别。
5. 点击「确认并渲染」。工作台显示最终黑白位图，PNG、原始位图导出和打印共用这条渲染路径。排版在本次应用运行期间保留，工作台可随时切回原有的文字或图片模式。

「插入二维码…」会直接在当前高级排版中添加二维码并打开编辑器。关闭编辑器或取消会保留上次确认的排版。高级排版不会修改远程打印模板。

## 导入模型生成的位图

让模型按 [本地位图 Skill](../Skills/paperang-local-raster/SKILL.md) 输出 raster1 JSON 和配套 PNG 预览。点击工作台「导入位图…」，选择 JSON 或工作台原先导出的 .raw。导入后直接显示原始点阵，核对后再使用原有打印按钮。浓度、送纸和份数仍在工作台设置。
