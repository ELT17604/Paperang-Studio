# 中转数据与保留（v0.3.0）

[身份与权限](AUTH-v2.zh-CN.md) · [升级](UPGRADE-v0.3.0.zh-CN.md)

SQLite 保存稳定身份、凭证摘要/Argon2id、公钥、会话摘要、限流、任务正文/raster1、投递元数据、状态事件和审计。普通网页接口不返回正文或 metadata；C 分页历史可查看和导出，M 只读自己活动 claim 的渲染字段。匿名不采集硬件指纹，IP/UA 仅用于投递及风控，不能证明真实自然人。

默认正文七天，审计九十天；清理在队列与投稿活动期间进行。数据库非端到端加密，正文未应用级加密，使用系统磁盘加密并保管 C 导出。历史保留 id、稳定 user_id、browser_id、credential_id、名称快照、正文/图片、时间、状态与可用事件；不把 claim/认证秘密放入导出。

轮换保持 user_id、撤销旧会话；吊销身份还拒绝排队任务。已送入打印机的数据无法召回。旧匿名历史不会依据 IP 合并到新身份。迁移备份必须保留在私有数据目录。
