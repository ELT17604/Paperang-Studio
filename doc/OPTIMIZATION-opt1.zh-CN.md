# opt1 代码与界面审阅

[English](OPTIMIZATION-opt1.md) · [版本登记](../VERSIONS.json)

## 版本与范围

兼容基线仍为 **0.3.1**。四个已实现分发统一为 `0.3.1-macclient-opt1`、`0.3.1-linuxrelayserver-opt1`、`0.3.1-winlite-opt1`、`0.3.1-relayskill-opt1`。中转 API v2、Mac 本地 API v1、模板 v1、raster1 schema1 保持不变。本次仅修改本地源码并构建，不等于已更新线上服务器或发布发行版。

## 实际清理与调整

- Mac：移除旧管理界面无调用的字段/类型、只写不读的私有正文缓存、无调用文档包装函数，以及重复的偏好写入。旧偏好读取保留用于迁移。蓝牙错误统一使用现有打印错误类型。
- 远程打印：拆为任务、连接、样式、管理四页。切换这四页保留独立 C 会话，便于预览；离开远程打印仍锁定。参数纵向分组、字段自适应排列；队列刷新后预览和发送中任务不消失，实际打印参数参与预览失效判断。未登录 C 时，选择队列摘要不再触发无权限的后台正文请求。
- Relay：移除不可达的 v1 public/admin/receipt/旧队列与正文分支及无调用辅助函数。仍在实际使用的设备状态机明确命名为内部 v2 适配器。外部 v1 仍返回 410，数据库迁移与 CLI 密钥导入保留。
- 网页：删除永远隐藏的旧正文/错误/阶段节点及无用样式；身份和配额使用简短摘要，完整身份折叠展示；优化窄屏登录与发送布局。前台每30秒刷新中转/会话，失败时禁用新投递；状态查询失败明确标记旧结果。文字与绘图保留统一投递流程。
- 更新检查：Mac/Windows 同时识别 fixN、optN；同基线中初始/fix 修订排在 opt 修订之前，计数按整数比较。后续优化使用 opt2 等，或升级数字基线；稳定更新检查仍排除其他分发与预发行版。只识别 fix 标签的旧客户端首次升级 opt1 需手动安装。
- RelaySkill：补充 macOS 实际存在的 STHeiti、Arial Unicode 中文字体路径。
- Windows：删除仅向已移出的测试程序集开放内部成员的属性文件；同步 opt1 元数据与版本比较。本轮没有运行原生 Windows 构建。

输入校验、权限、Cookie/CSRF、响应大小限制、活动认领隐私、纸仓/浓度检查、结果持久化、取消和防重打均保留。这些参与实际流程；本次不声称已证明所有平台的每一行都必不可少。
