# AndroidClient v0.3.3-androidclient

AndroidClient 是 Paperang Studio 的 Android 本地 P2 打印分发，使用现有 576 点 raster1 schema 1 与 P2 BLE 设备协议。Android 端从 0.3.3 独立编号，项目兼容基线为 0.3.x。

## 工作台与安装

[构建和工作台操作](../Android/README.md)涵盖文字、图片、多图层排版、二维码、黑白转换、raster1 / RAW、预览与导出、打印设置及本地历史。界面使用 Android 系统色板、圆角容器与分级操作按钮，参考 Material 3 Expressive 的色彩与形状。Android 13 或以上可安装本地签名调试候选包。

## Android 包名与 BLE 提速

此构建的应用 ID 为 `com.elt.pprstudio.adc`。按协商的 MTU 和 P2 流控在 20 字节默认负载与最高 180 字节之间选择写入上限，采用 MacClient 的 1008 字节协议帧和 10 ms 写入起始间隔。具体吞吐量以打印机和手机实际协商为准。

## 自动纸长、手绘与打印历史

高级排版默认按最后一行实际黑点截断高级排版，同时保留固定纸长。手绘支持全屏、继续编辑、本地素材库、透明图层复用与 raster1 JSON 导出。打印历史保存原始点阵与可编辑任务，可恢复编辑、插入插画或逐条删除。底部「素材」汇总所有手动保存的手绘。Android 13 模拟器覆盖尾部截断、触控笔迹渲染、素材重新加载、raster1 校验及历史文件删除。

## 编辑器纸长尺标

文字、图片、高级排版和全屏手绘均提供毫米尺标，以 300 DPI 换算实际渲染行数。全屏手绘提供顶部宽度尺和右侧长度尺，以独立的强调色底板标明毫米单位。排版尺标跟随画布平移与缩放，标记最终位图的末行。双指同向拖动平移纸面，改变指距围绕两指中心缩放。

## 验证范围

- 使用 SDK 36 / Build Tools 36.1.0 构建并校验 APK 签名，检查应用版本、蓝牙权限与入口。
- 用 MacClient Swift 原实现对照 CRC 握手与分包，校验接收端能重组分片并丢弃坏 CRC。
- Android 13（API 33）模拟器已验证应用启动、工作台自动预览和页面切换，以及文字、透明图、图层、二维码、raster1 校验、RAW/PNG、预设和历史读回。
- 实机验收项目包括界面与系统文件选择器、P2 扫描及连接、纸仓异常、浓度回读、长图分包、份间送纸、实际出纸与历史重启保留。当前无连接的 Android 手机和 P2，实机验收待执行。


## Android 实机验收步骤

| 场景 | 操作与预期 |
|---|---|
| 图文和预览 | 输入中文与多行文字，导入带透明区域的图片，切换四种内容模式。预览随编辑刷新，回到位图模式可恢复已导入的内容。 |
| 图层与二维码 | 插入文字框、标签、图片、二维码并让两个图层重叠。取消插入或取消层级修改时保留原排版。对部分文字先设粗体再取消粗体，检查选区之外保留原样式。用原始点阵预览检查小字并扫码。 |
| 输出一致性 | 导出 RAW 和 PNG。重新导入 RAW 后对比预览，检查黑点位置与原图一致，RAW 大小应为 72 字节乘纸长。 |
| P2 和异常 | 拒绝一次附近设备权限，再授予权限，扫描连接 P2 并读回电量、纸仓和浓度。开盖或缺纸时尝试打印，检查发送被阻止。合盖装纸后核对两份长图及份间送纸，另执行一次手动送纸。 |
| 历史 | 在打印中断和正常发送后分别检查记录，退出并重新启动应用，核对记录时间、份数、浓度、送纸参数和结果。 |
