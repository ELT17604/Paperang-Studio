# AndroidClient v0.3.3-androidclient

AndroidClient 是 Paperang Studio 的 Android 本地 P2 打印分发，使用现有 576 点 raster1 schema 1 与 P2 BLE 设备协议。Android 端从 0.3.3 独立编号，项目兼容基线为 0.3.x。

## 工作台与安装

[构建和工作台操作](../Android/README.md)涵盖文字、图片、多图层排版、二维码、黑白转换、raster1 / RAW、预览与导出、打印设置及本地历史。界面使用 Android 系统色板、圆角容器与分级操作按钮，参考 Material 3 Expressive 的色彩与形状。Android 13 或以上可安装本地签名调试候选包。

## Android 包名与 BLE 提速

此构建的应用 ID 为 `com.elt.pprstudio.adc`。按协商的 MTU 和 P2 流控在 20 字节默认负载与最高 180 字节之间选择写入上限，采用 MacClient 的 1008 字节协议帧和 10 ms 写入起始间隔。具体吞吐量以打印机和手机实际协商为准。

## 自动纸长、手绘与打印历史

高级排版默认在最后一行黑点处结束纸面，同时保留固定纸长。手绘支持全屏、继续编辑、本地素材库、透明图层复用与 raster1 JSON 导出。打印历史保存原始点阵与可编辑任务，可恢复编辑、插入插画或逐条删除。底部「素材」汇总所有手动保存的手绘。

## 编辑器纸长尺标

文字、图片、高级排版和全屏手绘均提供毫米尺标，以 300 DPI 换算实际渲染行数。全屏手绘提供顶部宽度尺和右侧长度尺，以独立的强调色底板标明毫米单位。排版尺标跟随画布平移与缩放，标记最终位图的末行。双指同向拖动平移纸面，改变指距围绕两指中心缩放。
