# Windows 客户端

[English](WINDOWS.md) · [构建](../Windows/README.md) · [文档目录](INDEX.zh-CN.md)

Paperang Studio WinClient 支持 Windows 10 2004+ / Windows 11，通过 USB 或蓝牙连接传统 Paperang P2。安装包包含运行时；使用便携目录时，应保留 exe 旁的文件。

## 连接打印机

1. 打开「打印机」，选择 USB 自动连接或蓝牙。
2. 蓝牙模式下打开 P2 并扫描。设备随发现即时显示，扫描中即可选择和连接，也可先停止扫描；信号变化不会丢失选择。
3. 查看连接卡片。选中不等于已连接；卡片区分选择、连接中、已连接、取消、断开和失败，并显示设备、USB/蓝牙及电量/纸仓状态。
4. 在本页刷新状态或断开。应用浓度和手动送纸需要先连接打印机。

## 编辑与打印

主区域为内容编辑与设置，右侧是自动更新的小预览，可单独放大。选择文字、图片、二维码、导入点阵或排版工具。将单独准备的内容加入排版，调整对象后确认排版，再打印或导出。

「导入文件」「导入 JSON」和拖放支持 PNG/JPEG/BMP/GIF/TIFF、RAW，以及 Mac/Android 的 schema 1 raster1 点阵和完整参数预设 JSON。预设恢复排版、图像处理、浓度、份数、送纸与传输参数，跨平台字体映射到 Windows 字体。错误文件不会覆盖当前内容；导入不自动打印。

默认满幅 576 点、四边 0 px、浓度 100、批后送纸 160 行。BLE 默认与 Android 一致：图像载荷 1008 字节、单次写入至多 180 字节、写入起点间隔至少 10 ms、无额外图像帧间隔、命令超时 6 秒、数据后等待 2 秒。设备流控可能增加耗时。已保存偏好保留原选择；连续纸带每批额外送纸默认 0 行。

开启全局允许耗纸，核对份数与送纸后点击「打印」。中断时可能已有部分数据进入打印机，请检查纸面后再决定是否重试。中转不确定任务保留认领记录，不自动重打。

## 中转与工具

- **远程打印：** 设置服务器与配对私钥或 M 执行密钥，选择自动接收或认领指定任务。预览未认领的完整内容需要 C 管理登录。
- **纸条模板：** 调整区块顺序与样式、示例预览、JSON 导入导出并保存应用。
- **访问管理：** 可独立填写服务器并使用 C 凭证登录，或使用已配对私钥。会话到期锁定，退出清除凭证和详情；配对不上传私钥。
- **本地 API：** 手动启用环回服务，Windows 默认端口 8766。请求需要令牌；耗纸另需全局开关和 `allowPaper:true`。见 [API 平台差异](API.zh-CN.md)。
- **纸带终端：** 手动文本或 Windows ConPTY Shell，支持缓冲导出、丢弃和打印；自动打印默认关闭。
- **设置与关于：** Windows 登录自启、无凭证正文的配置导出、版本和项目链接。

关闭窗口后接收器继续驻留托盘，本窗口的 API 和 Shell 停止；通过托盘「退出」结束程序。配置使用当前 Windows 用户加密，素材/正文只在明确保存时记录。为兼容旧配置和待回报任务，历史存储标识继续保留。
