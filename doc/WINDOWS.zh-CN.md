# Paperang Studio · V0.3.0-winlite

> **v0.3.0:** [鉴权合同](AUTH-v2.zh-CN.md) · [升级步骤](UPGRADE-v0.3.0.zh-CN.md) · [Agent 接手](HANDOFF-v0.3.0.zh-CN.md)。WinLite 设置含 C 图形化管理；历史正文不再向网页/普通执行凭证开放。

[English](WINDOWS.md) · [Windows 源码](../Windows/README.md)

Paperang P2 的 Windows 原生轻量托盘客户端。基于 ELT Group 的 [Paperang Studio](https://github.com/ELT17604/Paperang-Studio) macOS 客户端逻辑移植，使用 C# / .NET 10、WinForms 和 Windows BLE GATT。启动直接驻留托盘，双击托盘打印机图标或右键 → 设置进入配置。

## 使用

1. 解压发布包到固定目录，运行 `PaperangStudio.exe`。首次运行只显示托盘提示，不弹主页面。
2. 双击托盘图标，填入中转服务器根地址，选择**已配对的所有者私钥 JSON 文件**。M 设备密钥没有 C 管理权限。
3. 开启电脑蓝牙和 P2，点击“扫描 P2”，选择自己的打印机，然后“保存并连接”。避免手机或 Mac 客户端同时占用同一台打印机。
4. 默认每次连接自动允许打印。关闭设置窗口后继续在托盘接收纸条；托盘菜单可暂停、恢复、断开、重连和退出。
5. “启动与状态”可选择“登录 Windows 时自动启动并驻留托盘”。这是当前用户的登录启动项，不需要管理员权限；若 Windows 任务管理器中禁用了该启动项，需要在那里重新启用。

**系统：Windows 10 2004 / Windows 11，支持 BLE 的蓝牙适配器。** 当前提供 x64；可用构建脚本生成 ARM64。`lite` 包依赖 **.NET 10 Desktop Runtime**，已有运行时的电脑可直接运行；`portable` 包附带运行时，解压即用，体积较大。无需 Python、Node、WebView 或打印机驱动。

## 与 macOS 一致的模板编辑

设置 → 打印 → 图形化样式编辑器。支持便签、小票、复古电传、访客纪念四套预设，以及自定义模板。

- 标题、正文、投稿身份、时间、任务编号、IP、UA、浏览器信息、分隔线、自定义文字，共十种区块。
- 模板改名、复制、载入预设、删除；区块增删、启停、拖动排序、上移/下移。
- 字体、字号 8–96、粗体、左/中/右对齐、左右边距 0–120 点、上方留白 0–200 行。
- 纸面点击选区块，横向拖动调边距，纵向拖动调上方留白；文字与绘图示例可切换，示例正文可编辑。
- 与 macOS **v1 模板 JSON** 双向兼容，单模板导入/导出。最多 30 个模板、24 个区块/模板，导入上限 64 KiB。
- 变量 `{{text}} {{sender}} {{id}} {{time}} {{ip}} {{ua}} {{device}}` 只替换一遍，访客正文中的变量不会继续展开。
- 正文区块同时承载图片与说明。图片按边距等比适配，边距为 0 保持原点阵；关闭正文会同时隐藏图片和说明。总高度最多 1400 行。

编辑器“保存并应用”会立即持久保存并用于后续纸条，不影响正在发送的任务。当前样式、模板选择和打印选项也会自动保存，关闭设置刷新落盘，重启后恢复。取消丢弃草稿。使用预设以外的已保存模板时，在设置中选择“自定义”和模板，然后“保存并连接”。预览与实际打印共享区块渲染器。由于系统字体不同，像素字形和折行不保证与 macOS 完全相同；JSON 保留原字体名，PingFang SC 映射微软雅黑、Menlo 映射 Consolas、Helvetica 映射 Arial。

## 后台行为与凭证

- 中转每 2 秒上报/轮询，按创建时间处理排队任务。长文字与图片先读完整详情，校验 `raster1` 尺寸与 SHA-256，之后才认领。
- 使用 FF00/FF01/FF02/FF03 的原版 BLE 路径，保留流控、CRC key-zero 握手、P2 型号校验、纸仓检查与浓度回读。默认浓度 100、批后送纸 150 行。
- 每项认领在发送任何打印数据前写入加密记录；正常结束先保存 `sent`，再回报服务器。进程中断后只回报 `unknown`，不会自动重打旧认领。服务器不可用时结果留待下次连接回报。
- 默认持续重连：首次失败后的 5 次重试耗尽后等待 60 秒，再尝试 5 次并循环直到成功；可在设置关闭此选项。断开/退出立即取消等待。打印机掉线每 30 秒尝试重连记住的地址，不自动更换设备。
- 暂停影响新领取任务，已发送到打印机的数据无法撤回。出纸异常会暂停自动打印，需要检查纸面后手动恢复。
- 凭证、偏好、模板与未回报记录通过当前 Windows 用户 **DPAPI** 加密，原子写入 `%LOCALAPPDATA%\ELT\PaperangStudioWinLite`，不保存纸条正文或明文密钥日志。不要将这两个 `.dat` 文件当作跨用户备份；只能由原 Windows 用户解密。
- 重复前台启动唤起已有实例设置，重复 --background 启动保持静默。关闭设置继续驻留；退出、注销、关机、睡眠会影响通信，不是系统服务或防休眠工具。

`sent` 表示发送完成，仍需核对纸面；不会自动声称已人工确认。本版提供托盘接收、模板编辑和完整 C 图形化管理；macOS 的主工作台、PTY、工程写入、本地 HTTP API 不在 Lite 范围。服务器、网页和参与客户端必须一同升级到 v0.3.0。

当前版本的统一命名与跨端范围见[版本规则](VERSIONING.zh-CN.md)、[功能实现矩阵](FEATURE-MATRIX.zh-CN.md)。

## C 图形化管理

设置→管理：默认支持所有者私钥登录、凭证创建/展示名称/轮换/吊销、身份与浏览器会话、公钥、完整历史与正文/图片选项卡、唯一用户筛选、分批 JSONL 导出和人工纸面确认。管理会话十分钟后自动锁定，不影响使用所有者身份的后台打印。Owner 文件写入前设置仅当前用户 ACL。


### v0.3.1-winlite-fix1 管理中心

左侧切换分类；上方仅显示当前分类可用的操作；中间是表格，下方查看详情。新建凭证使用独立表单：凭证 ID、默认新身份 ID 和随机密钥由服务器生成；已有身份从列表选择，无需粘贴 UUID。口令留空时自动生成。生成私钥须先解锁管理，公钥登记成功后自动写入 ID，禁止覆盖已有私钥文件。

凭证和身份默认隐藏已吊销项，可取消勾选查看。每页可选 25、50、100 条，提供上一页、下一页和页码/本页数量；最多缓存最近 12 页，切换分类、筛选或页大小会重置。旧服务器固定分页也能逐批读取并保留溢出记录，不会因本地裁剪漏项。新版服务器支持先筛选再分页及不含正文的历史摘要；只在选中任务时读取完整正文/图片。旧服务器仍按原接口传输每批最多五条完整任务，客户端页缓存仅保留摘要。服务器增强代码需要另行部署；本机界面、隐藏与分页已兼容当前 v0.3.1 服务。

验证：Windows 54 项回归、Server 33 项测试通过；实际窗口检查了分类、隐藏和新建表单默认项，未在生产创建/吊销测试凭证。使用当前所有者配置连接，原模板和打印设置保留。


### v0.3.1-winlite-fix2 自动保存与配置导出

连接地址、所有者私钥路径、HTTP 开关、打印机选择、自动连接/打印、持续重连、登录启动、打印参数和模板都会在更改后约 350 ms 自动保存，关闭窗口时再刷新一次。设置和管理窗口的分类、分页大小、隐藏吊销项、身份筛选和扫描显示选项也会记住。管理窗口切换私钥并验证成功后，会同步保存新路径。

本地 `settings.dat` 为可恢复的有效配置；`settings-draft.dat` 单独保留未完成的连接草稿；`ui.dat` 保存界面偏好，均使用当前 Windows 用户 DPAPI 加密。草稿无效或有原连接待回报任务时不覆盖恢复所需的连接。无需联网也能保存设置。有效连接更改在下次启动使用，当前运行的连接可点击“保存并连接”切换；修改本地偏好不会自动打断正在发送的任务。

“启动与状态 → 导出全部配置”导出带版本和 schemaVersion 的 JSON，包含模板、所有设置、界面偏好及私钥路径，不包含私钥文件内容、原始密钥、短期会话或待回报任务。禁止将配置导出覆盖到当前私钥路径。换机时需要单独迁移私钥并调整路径；此版提供配置导出，未提供图形化导入。

验证新增配置/草稿/界面偏好的重启读取、DPAPI 加密及导出内容与凭证排除检查；Windows 共 60 项回归通过。服务端协议无需改动。
